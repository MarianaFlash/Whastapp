Vincula tu WhatsApp

Esta herramienta se conecta como un dispositivo vinculado, igual que WhatsApp Web.

  1. Abre WhatsApp en tu teléfono.
  2. Toca ⋮ o Ajustes → Dispositivos vinculados.
  3. Toca Vincular un dispositivo y escanea este código.

El código se renueva solo cada pocos segundos.
